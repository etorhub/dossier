# 500 Error Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a styled, branded 500 error page with a "Try again" reload button and a "Go to feed" link when a Flask route raises an unhandled exception.

**Architecture:** A single `@app.errorhandler(500)` registered in `create_app()` renders `templates/500.html`, which extends `base.html`. HTMX partial requests receive a bare 500 with no body to avoid injecting a full page into a swap target. All strings are i18n-wrapped.

**Tech Stack:** Flask, Jinja2, Flask-Babel, HTMX 1.9, pytest

- [ ] **Step 1: Add three failing tests**

Append to `tests/test_health.py`:

```python
def test_500_returns_status_code(app: Flask, client: FlaskClient) -> None:
    """500 error handler returns HTTP 500."""
    @app.route("/test-500-status")
    def _trigger() -> str:
        from flask import abort
        abort(500)

    response = client.get("/test-500-status")
    assert response.status_code == 500


def test_500_returns_html_with_error_message(app: Flask, client: FlaskClient) -> None:
    """500 error handler renders the branded error page."""
    @app.route("/test-500-html")
    def _trigger_html() -> str:
        from flask import abort
        abort(500)

    response = client.get("/test-500-html")
    assert b"Something went wrong" in response.data
    assert b"Try again" in response.data
    assert b"Go to feed" in response.data


def test_500_htmx_request_returns_empty_body(app: Flask, client: FlaskClient) -> None:
    """500 error handler returns empty body for HTMX partial requests."""
    @app.route("/test-500-htmx")
    def _trigger_htmx() -> str:
        from flask import abort
        abort(500)

    response = client.get("/test-500-htmx", headers={"HX-Request": "true"})
    assert response.status_code == 500
    assert response.data == b""
```

### Task 2: Register the error handler in `create_app()`

**Files:**
- Modify: `app/__init__.py`

- [ ] **Step 1: Add the import and the error handler**

In `app/__init__.py`, the existing imports at the top include:
```python
from flask import Flask, Response, redirect, request, session, url_for
```

Add `render_template` to that import:
```python
from flask import Flask, Response, redirect, render_template, request, session, url_for
```

Then, inside `create_app()`, just before the final `return app` line, add:

```python
    @app.errorhandler(500)
    def internal_error(e: Exception) -> Response | tuple[str, int]:
        if request.headers.get("HX-Request"):
            return Response(status=500)
        return render_template("500.html"), 500
```
